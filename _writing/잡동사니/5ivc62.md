글을 쓰다 보면
자꾸 까먹습니다.
그래서 적어 둡니다.

상자 안처럼 쓰면
그 아래처럼 나온답니다.
헷갈리면 그냥 미리보기를 누르면 됩니다.

## 줄바꿈과 문단

엔터 한 번이면 줄이 바뀌고
한 줄을 비우면 문단이 나뉩니다.

```
첫 줄
둘째 줄

한 줄 비우고 쓴 줄
```

첫 줄
둘째 줄

한 줄 비우고 쓴 줄

## 꾸미기

글자 사이에 넣어 쓰는 것들입니다.
표시를 그냥 글자로 보이게 하려면 앞에 `\` 를 붙이면 되구요.

| 이렇게 쓰면 | 이렇게 나옵니다 |
|---|---|
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `~~지운 글자~~` | ~~지운 글자~~ |
| `` `코드` `` | `코드` |
| `\*별표\*` | \*별표\* |

## 링크

보일 글자는 대괄호에, 주소는 괄호에 넣습니다.
주소를 그대로 보이게 하려면 꺾쇠로 감싸면 됩니다.

```
[소개 글](/about/)
<https://naver.com>
```

[소개 글](/about/)
<https://naver.com>

## 소제목

이 글의 '줄바꿈과 문단', '꾸미기' 같은 제목이
줄 앞에 `##` 을 붙여 쓴 겁니다.
`#` 을 하나 더 붙이면 한 단계 작아집니다.
`#` 하나짜리는 글 제목 자리라 둘부터 쓰는 게 좋답니다.

```
### 조금 작은 소제목
```

### 조금 작은 소제목

## 인용

줄 앞에 `>` 를 붙입니다.

```
> 인용할 때는 이렇게 하랍니다.
```

> 인용할 때는 이렇게 하랍니다.

## 목록

줄 앞에 `-` 나 `1.` 을 붙입니다.
안쪽 목록은 앞에 띄어쓰기 두 칸을 넣습니다.

```
- 과일
  - 사과
  - 배
- 채소

1. 첫째
2. 둘째
```

- 과일
  - 사과
  - 배
- 채소

1. 첫째
2. 둘째

## 가로줄

장면을 끊을 때 씁니다.
위에 한 줄은 꼭 비웁니다.
붙여 쓰면 윗줄이 소제목으로 바뀌어 버린답니다.

```
앞 장면

---

뒤 장면
```

앞 장면

---

뒤 장면

## 코드

여러 줄짜리 코드는
숫자 1 왼쪽 키의 `` ` `` 를 세 개 써서 위아래를 막습니다.
첫 줄에 언어 이름을 적으면 색이 입혀집니다.

````
```python
def hello():
    print("안녕")
```
````

```python
def hello():
    print("안녕")
```

## 표

칸은 세로 막대로 나누고
둘째 줄의 `---` 가 제목 칸과 내용을 가릅니다.

```
| 이름 | 값 |
|---|---|
| 첫째 | 1 |
| 둘째 | 2 |
```

| 이름 | 값 |
|---|---|
| 첫째 | 1 |
| 둘째 | 2 |

## 그림

글 쓰기 화면에 붙여 넣거나(Ctrl+V) 끌어다 놓으면
이런 줄이 알아서 들어갑니다.
대괄호 안에 설명을 적어 두면 그림이 안 뜰 때 대신 보입니다.
이건 직접 넣어 보는 게 빠릅니다.

```
![바다 사진](/assets/img/사진.jpg)
```

## 날짜를 맨 앞에 쓸 때

줄 맨 앞에 숫자와 점을 쓰면
번호 목록으로 바뀌어 버립니다.
첫 점 앞에 `\` 를 붙이면 그대로 나옵니다.

```
2026\. 10. 3. 맑음
```

2026\. 10. 3. 맑음
