글 쓰기

이 쪽은 글쓴이가 글을 쓰는 곳입니다. 글은 왼쪽 항목에서 찾아 읽을 수 있습니다.

GitHub 연결

  1. 토큰 만들기 화면 열기를 누릅니다. 열린 GitHub 화면의 Repository access 에서 Only select repositories 를 고르고 이 사이트의 저장소를 선택한 다음, 맨 아래 Generate token 을 누릅니다.
  2. 나온 토큰(github_pat_ 로 시작하는 긴 글자)을 복사해 아래 칸에 붙여 넣고 연결하기를 누릅니다.

토큰은 이 브라우저에만 저장됩니다. 남과 같이 쓰는 컴퓨터에서는 연결하지 마세요. GitHub 의 Settings → Developer settings 에서 언제든 폐기할 수 있습니다.

임시저장 글

    임시저장한 글이 없습니다.

    임시저장 글은 이 브라우저에만 저장됩니다. 사이트와 GitHub 에는 올라가지 않아 다른 사람은 볼 수 없습니다. 다른 기기에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 함께 지워집니다.

    새 글

    게시하기 지우면 되돌릴 수 없습니다.
